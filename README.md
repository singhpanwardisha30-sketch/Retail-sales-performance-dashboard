# Retail Sales Performance Dashboard

## Project Overview
An interactive retail sales dashboard built using Microsoft Excel to analyze sales performance, profitability, regional trends, product categories, and customer segments.

## Business Objective
The goal of this project is to turn retail sales data into useful business insights that can support performance monitoring and data-driven decision-making.

## Tools & Skills
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and interactive filtering
- KPI cards and dashboard design
- Data analysis and business reporting

## Dashboard Features
- **Total Sales:** Overall revenue generated
- **Total Profit:** Overall profit earned
- **Total Orders:** Number of orders analyzed
- **Average Order Value:** Average sales value per order
- **Sales by Region:** Compare regional performance
- **Sales by Category:** Analyze product category performance
- **Interactive Filters:** Filter the dashboard by region, category, and customer type

## Dataset
The project uses a retail sales dataset containing 300 orders, including sales, profit, region, category, product, and customer type.

## How to Use
1. Download `Retail_Sales_Performance_Dashboard.xlsx` from this repository.
2. Open the workbook in Microsoft Excel.
3. Navigate to the dashboard sheet.
4. Use the slicers to filter results and explore different business views.
